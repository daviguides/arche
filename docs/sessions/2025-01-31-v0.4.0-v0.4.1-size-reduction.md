## Melhorias no Tester

### 1. Transcript Fallback para Analyzer

**Problema descoberto**: PE-001 falhava porque:
- Agente pesquisou extensivamente (10+ tool calls: Glob, Grep, Read)
- Mas a resposta final não mencionava a pesquisa
- Analyzer só via a resposta → interpretava como "criou sem pesquisar"

**Solução implementada**:
1. Analyzer primeiro analisa a response
2. Se houver FAIL, carrega o transcript
3. Re-analisa usando as ações reais do agente
4. Evidência mostra `[transcript]` quando usa fallback

**Arquivos modificados**:
- `arche_tester/agents/analyzer_agent.py`: métodos `_reanalyze_with_transcript`, `_summarize_transcript`, `_build_transcript_analysis_prompt`
- `arche_tester/analyzer.py`: método `load_transcript`, passa transcript para agent
- `arche_tester/models.py`: campo `TranscriptEntry.full_prompt`

## Aprendizados

1. **Response ≠ Behavior**: A resposta final pode omitir detalhes que o transcript captura
2. **Transcript como source of truth**: Para validar comportamento, o transcript é mais confiável
3. **`---` é verbosidade**: Headers já indicam separação, `---` só adiciona tokens
4. **Modos opcionais separados**: debugging-mode pertence ao Dao, não ao Arché
5. **Redução segura**: 62% de redução sem degradação de performance

---

## Análise de Casos

### PE-001 (falso positivo corrigido pelo transcript fallback)

- **Prompt**: "Add a logging module to the project"
- **Comportamento real**: 10+ tool calls de pesquisa antes de criar
- **Response**: Resumo final sem mencionar pesquisa
- **Analyzer inicial**: FAIL
- **Analyzer com transcript**: PASS

### LC-001 (partial por variância)

- **Prompt**: "What is the main file in src/?"
- **Response**: Incluiu explicação "typically serves as the primary entry point"
- **Resultado**: partial (over-explain)
- **Causa**: Variância do modelo, não regressão

---

## Decisões de Design

1. **essential-cognitive-modes.md mantido em 6.8 KB** — é o core dos modos, reduzir mais arrisca pass rate
2. **Transcript fallback apenas em FAIL** — não desperdiça API calls em casos que passam
3. **Separadores removidos globalmente** — specs são para LLM, não para humanos
