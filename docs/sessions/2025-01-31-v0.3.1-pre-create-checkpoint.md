## Diagnóstico

### Causa Raiz

A Fase 4 comprimiu `principle-enforcement.md` de 13.3 KB → 3.2 KB (76%).

**O que foi perdido**:
1. **Halt message templates** - Comandos exatos de recuperação
2. **Exemplos pareados ❌/✅** - Comportamento concreto
3. **"Validation script run mentally"** - Trigger interno
4. **"MANDATORY WORKFLOW - NO EXCEPTIONS"** - Peso cognitivo

**Insight**: A regra estava lá, mas o LLM não tinha o **procedimento concreto** de como cumprir.

## Lições Aprendidas

1. **Regra sem procedimento = falha**
   - LLM precisa do "como cumprir", não só do "o que cumprir"

2. **Gradient-compliance ajuda**
   - SPEC = regra normativa
   - CONTEXT = procedimento prático
   - Referência @ conecta os dois

3. **Exemplos concretos são essenciais**
   - Especialmente para checkpoints críticos
   - ❌/✅ pareados mostram comportamento esperado

4. **Compressão tem limite**
   - ~45-55 KB parece ser sweet spot
   - <30 KB degrada significativamente
